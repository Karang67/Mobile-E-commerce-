> **Shivangi Mobile** is an enterprise-grade, omnichannel retail and e-commerce web platform engineered for modern smartphone retailers. It delivers an app-like Progressive Web App (PWA) storefront for customers, a dedicated pre-owned/refurbished device marketplace with quality inspection scoring, interactive EMI calculation, dynamic UPI QR and Cash-on-Delivery checkout, seamless WhatsApp omnichannel ordering, and a secure JWT-authenticated Admin ERP portal backed by Node.js, Express, MongoDB Atlas, and Cloudinary.

## 🚀 Quick Start

### 1. Run the Frontend (Vite)
```bash
npm install
npm run dev
```
*Frontend runs at `http://localhost:5174` (or available port).*

### 2. Run the Backend API (Express)
```bash
cd server
npm install
npm run dev
```
*Backend runs at `http://localhost:5001`.*
